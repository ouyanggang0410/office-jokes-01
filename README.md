## The joke

> We hired a consultant to tell us our meetings were the problem, then he billed us for the meeting where he told us.

One line about office life, 115 characters. The turn: the consultant hired to
fix the meetings problem bills the client for the very meeting where he
delivers that verdict.

## How it works

`main.py` writes the joke to `/output/entry.txt` (UTF-8, 1–199 characters,
single line) and reads it back to verify the content before exiting.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
